# SelfUs.art — GitHub Pages

Déposez les six fichiers de ce dossier à la racine de votre dépôt GitHub : `index.html`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest`, `README.md`.

Dans Settings → Pages, choisissez **Deploy from a branch**, la branche principale et le dossier **/(root)**. Le site doit être accessible en HTTPS.

Sur iPhone, ouvrez le site avec Safari puis utilisez **Partager → Sur l’écran d’accueil → Ajouter**. Si une ancienne icône persiste, supprimez le raccourci et ajoutez-le à nouveau.
